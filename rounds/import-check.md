# Import check

One file, one import. It covers what the finished tool does that has not yet been tried in Canvas:
unpublished weeks, a published Start Here module and home page, pages inside a module, quizzes with
no points, and the annotation note.

## How to import
1. Use a **new, empty** sandbox course (or empty one with *Settings → Reset Course Content*). Import it **once**.
2. *Settings → Import Course Content → Common Cartridge 1.x Package*, choose `rounds/import-check.imscc`, pick *All content*, and click *Import*.
3. Wait for the job to say Completed, then go through the list.

## What to check
- [ y] The import finished with no errors or warnings listed. (If it listed any, copy them into Results.)
- [ y] Modules: **Start Here is published** and holds Welcome, Syllabus, and Introduce yourself, all published.
- [y ] Welcome and Syllabus open as pages. The link on the Syllabus page opens the course Syllabus.
- [ y] Every week module, and everything inside it, is **unpublished**.
- [ y] Home shows the front page with four headings (Welcome, Syllabus, Communication preferences, Start Here), and both links on it work.
- [y ] Quizzes: Midterm exam and Final exam are Classic Quizzes with 0 points and no questions, and there is exactly one of each.
- [ y] Reading response 1 shows the note "Attach your document in Canvas before students see this." and, under Edit, offers file upload, text entry, annotation, and media recording.
- [ y] Assignments page: Discussions 25% (drop lowest 1), Weekly work 30%, Exams 35%, Participation 10%, Extra credit 3%.
- [ y] Week 1 starts with the header "Tue Jan 26 — What is psychology? · Readings: Myers Ch. 1; Milgram (1963)", and Week 8 has "Thu Mar 18 — No class · Spring break".
- [y ] Reading response 8 is due Fri Mar 19 at 11:59 pm.
- [y ] Optional, in Student View: give the test student full marks on everything, including "Extra credit: museum visit". Does the total go above 100%?
